# Artificial Intelligence Fundamentals

This repository contains two comprehensive project developed for **Artificial Intelligence Fundamentals** course (BI-ZUM) at **FIT CTU in Prague**.\
This project covers basics of Artificial Intelligence:
- State space exploration
- Heuristics
- AI Planning

## 🚀 Project Overview

### [Task 1: State space exploration](./01/)
A visual illustration of path finding algorithms
* **Algorithms:**
  * Breadth first search (BFS)
  * Depth first search (DFS)
  * Greedy search
  * Random search
  * Dijkstra algorithm
  * A\*
* **Key Focus:**
  * Comparison of each algorithm
  * Understanding of A\* heuristic
  * Optimal & non-optimal search algorithms
  * Deterministic & non-deterministic algorithms
 
### [Task 2: Traveling Salesman Problem](./02/)
A visual illustration of unraveling of TSP path.
* **Heuristic:**
  * Simulated Annealing
* **Key Focus:**
  * Convergence of heuristic algorithm to local minima
  * Using heuristics to approximate a solution to a NP-Hard problem
  
### [Task 3: AI Planning](./03/)
PDDL for a robots stacking up a tower of boxes.
* **Key Focus:**
  * Understanding AI Planning
  * Converting a intuitive problem to a domain definition problem
  * Exploitation of a domain solver
 
### [Task 4: Semestral Work - Sudoku as a CSP](./semestralka/)
Constraint satisfaction problem as a Linear Programming and Boolean satisfiability problem (SAT)
* **Key Focus:**
  * Problem representation as a CSP
  * Comparison between different methods (LP vs SAT)
  * Protocol creation
